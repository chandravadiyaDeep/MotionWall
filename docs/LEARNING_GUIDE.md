# MotionWall Learning Guide

Use this as a study journal. For each topic, write: what it is, why MotionWall needs it, a small code example, what you tested, and what you learned.

## V0.1 topics

- Kotlin source files, packages, functions, classes, and null safety.
- Android project structure: app module, source sets, resources, manifest.
- Gradle: plugins, dependencies, build types, wrapper.
- Activity lifecycle and app entry point.
- Debug vs release APK.
- Install APK with Android Studio or ADB.

## V0.2 topics

- Composable functions and modifiers.
- State and recomposition.
- Lists, lazy grids, navigation.
- Theme, typography, shapes, and animation.

## V0.3 topics

- Data classes and serialization.
- Repository pattern.
- Local asset management.
- Filtering, search, and sorting.

## V0.4–V0.6 topics

- Media playback and surface lifecycle.
- WallpaperService and Engine callbacks.
- Native system preview/confirmation.
- Rendering loop, touch handling, frame pacing, GPU/CPU usage.

## V0.7–V1.0 topics

- Room and DataStore.
- WorkManager and file storage.
- Profiling, crash/ANR diagnostics, compatibility testing.
- App versioning, signing, release channels, changelogs.

## Learning rule

Do not copy a large implementation without understanding it. Before merging a milestone, explain its important files and lifecycle in your own words.
